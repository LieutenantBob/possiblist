# Possiblist° — Roadmap

## v2 Features

### User Accounts & Persistence
- Cross-device quiz history with user accounts
- Persistent score tracking across sessions
- Profile page with long-term progress

### Adaptive Quiz Ordering
- Machine-learned question ordering based on user's weakest categories
- Spaced repetition for revisiting previous wrong answers
- Difficulty progression based on session performance

### Admin CMS
- Content management interface for fact cards and editorials
- Editorial workflow: draft → review → publish
- Bulk content operations

### Automated Weekly Digest
- Cron-triggered email send via Resend (template built in v1)
- Subject: "5 things you were wrong about this week (probably)"
- Send: Mondays 8am GMT
- Personalised based on user's quiz history

### B2B / Classroom Mode
- Institutional licensing with team management
- Classroom view: teacher sees aggregate student misconceptions
- Exportable reports for educational settings
- Custom question sets per institution

### Content Expansion
- Cards 6–21 added post-launch via content pipeline scripts
- Multilingual content (starting with Spanish, French, German)
- Guest editorial contributions

### Downloadable Fact Card PDFs
- Printable single-page fact card summaries
- Mention on subscribe page as premium benefit

### Search
- Full-text search across fact cards and editorials
- Category filtering
- Tag-based discovery

### Mobile App
- React Native app wrapping the web experience
- Push notifications for new cards and weekly digest
- Offline mode for completed quizzes

### Comment Sections
- Moderated discussion on article pages
- Premium-only commenting to maintain quality

### Enhanced Analytics
- A/B testing framework for quiz card ordering
- Conversion funnel optimization
- Shareability tracking per card
